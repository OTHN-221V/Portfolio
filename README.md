- Designed a real-time **HMI**, reducing diagnostic time from several hours to minutes.
- Developed **Raspberry Pi** supervision for instant remote monitoring and an interactive maintenance chatbot (Python/Snap7).

**Stack:** `Siemens S7-300` `TIA Portal` `Ladder` `SCL` `HMI` `Raspberry Pi` `Python` `Snap7`

</details>

<details>
